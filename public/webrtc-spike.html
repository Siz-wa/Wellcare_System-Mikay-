WebRTC Spike — WellCare Phase 1

Proves a peer connection establishes before Phase 3 UI work. Manual signalling; no Reverb, Echo or Pusher installed.

How to run it

  1. Open this page in two tabs (or two browsers/machines on the same network).
  2. Tab A: Start camera, then Create offer. Wait for ICE gathering to read complete, then copy the blob.
  3. Tab B: Start camera, paste into Remote blob, then Accept offer. Copy the answer blob it produces.
  4. Tab A: paste the answer into Remote blob and press Apply answer.
  5. Both tabs should show two live videos and connected.
